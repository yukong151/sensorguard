# SensorGuard 个人信息保护影响评估 (PIA)

> P4-7 (文档 §15 交付物 #6):个人信息保护影响评估
> 适用:《中华人民共和国个人信息保护法》第 55 条、《GB/T 35273-2020 个人信息安全规范》
> 版本: v1.0 · 日期: 2026-08-13

## 1. 处理活动概述

| 项 | 内容 |
|---|---|
| 处理者 | SensorGuard(com.yuexiao12.sensorguard) |
| 处理目的 | 传感器与权限使用透明度监测(反窃听) |
| 处理方式 | 端侧本地处理,完全离线 |
| 涉及个人信息 | 无用户可识别信息(见 §2) |

## 2. 是否构成"个人信息处理"?

**结论:不构成(或仅构成最低限度、去标识化的设备本地数据处理)。**

依据个保法第 4 条,个人信息指"以电子或其他方式记录的与已识别或可识别的自然人有关的各种信息"。
SensorGuard 处理的数据:

| 数据类型 | 是否属个人信息 | 说明 |
|---|---|---|
| App 对传感器的调用事件(时间/时长/采样模式) | **否** | 描述"App 行为",非自然人的"信息",且无身份关联字段 |
| 12B 匿名哈希指纹(非包名明文) | 去标识化 | HMAC-SHA256(pkg, device_salt) 截断,不可逆、不可反向定位 |
| 系统状态信号(前后台/屏幕/是否在场) | **否** | 设备本机状态,非个人信息 |
| 传感器原始波形 | **不采集** | 明确不处理 |

**关键:本 App 零网络权限,数据永不出设备,不构成"向境外提供/委托处理/共享"等更高风险场景。**

## 3. 处理的合法性基础(个保法第 13 条)

- **第 13 条第 1 项:取得个人的同意** —— 首次启动时明示隐私政策并征得同意;
- 第 13 条第 7 项(合理范围内处理已公开信息)不适用;
- 因数据不出端、无共享/跨境,不触发第 39(跨境)条单独同意。

## 4. 影响评估(风险 × 可能性 × 严重度)

| 风险场景 | 可能性 | 严重度 | 缓解措施(已落实) |
|---|---|---|---|
| 事件日志泄露被第三方读取 | 低(数据仅本机加密库) | 中 | AES-256-GCM + DEK/KEK + Android Keystore,密钥不可导出 |
| 攻击者物理接触设备解密日志 | 中 | 中 | 文档 §2 明确"物理接触威胁不在防护范围"写入隐私政策 |
| App 自身恶意收集 | 免及 | 高 | 零网络权限(无 INTERNET),无 SDK,开源可审计 |
| 哈希指纹碰撞导致 App 识别 | 极低(12B≈2^96) | 低 | 12B HMAC 截断 + device_salt 每设备不同 |
| 包名明文泄露(Shizuku 增强) | 中(仅内测版) | 低 | store 版禁用 Shizuku 归因仅内测显示 |

**综合风险等级:低(LEGAL_LOW)** —— 数据不出端 + 去标识化 + 加密存储三重保障。

## 5. 数据保护措施清单(与文档 §7 逐条对应)

- ✅ **权限最小化**: 仅 5 个权限,不申请 QUERY_ALL_PACKAGES / PACKAGE_USAGE_STATS
- ✅ **零网络**: 主进程无 INTERNET 权限,数据永不出端
- ✅ **加密存储**: AES-256-GCM + DEK/KEK 双层密钥,30 天轮换
- ✅ **遗忘权**: 一键擦除 = 销毁 DEK,密文不可再读
- ✅ **透明**: 隐私政策 + 事件日志可本地查看
- ✅ **供应链**: SBOM (CycloneDX) + 版本锁定 + Semgrep/MobSF 扫描

## 6. 用户权利实现(个保法第 44-49 条)

| 权利 | 实现 |
|---|---|
| 知情权 | 隐私政策 + 应用内事件查看 |
| 删除权 | 一键擦除全部日志(销毁密钥) |
| 更正权 | 不适用(不采集个人数据) |
| 撤回同意权 | 停止监测服务即中断处理 |
| 可携权 | 不适用(无个人数据可携) |

## 7. 结论与建议

**SensorGuard v1.0 通过 PIA 评估,合规风险低。** 无需向监管机构进行事前评估(不涉及敏感个人信息、自动化决策、公开信息处理)。上架商店时随隐私政策一并提交本评估作为合规佐证。
